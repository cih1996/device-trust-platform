# 知衡后台 0.7

后台按“总览 → 设备 → 事件”重新组织。顶部下拉框随时切换应用（含“全部应用”），所选应用保存在地址中，链接可直接分享。

## 风险总览

- 时间范围：24 小时（按小时）、7 天、30 天（按天）。指标与上一个同长度周期对比。
- 指标：业务事件、活跃设备与新设备、高风险事件、建议核验、平均风险分、关联账号与独立 IP、平均页面停留。
- 图表：按风险等级拆分的事件趋势、设备风险分布、平均风险分、活跃设备、业务场景、风险线索排行、访问 IP（设备数与账号数）、设备品牌与访问地区。
- 指标、图表和列表均可点击，进入对应的设备或事件筛选。

## 设备风险评分

设备评分 = 环境评分 + 业务评分（上限 100）：

- 环境评分：最近一次上报命中的设备线索（调试、模拟环境、VPN、应用不匹配、多项系统修改线索）加环境验真矛盾（最多 50 分）。
- 业务评分：7 天内该设备业务事件中业务行为规则（频次、多账号、支付等）的最高分，不含事件当时的环境分。环境恢复正常后，下次上报即降分。

等级：≥70 高风险，30–69 中风险，<30 低风险。设备列表支持按等级筛选，并可按风险评分、最近活跃、关联账号、业务事件排序。

设备详情提供评分构成、环境验真、近 30 天风险与事件趋势、业务事件、设备参数、应用与签名、网络与定位、关联账号与使用过的 IP。

## 风险事件

分页列表，支持时间范围、风险等级、业务场景、处置状态、关键字（账号 / 事件 ID / 设备 / IP）和单台设备筛选。点击行打开详情侧栏，可批准、拒绝或标记异常 / 正常。

## 新增管理接口

| 接口 | 说明 |
|---|---|
| `GET /api/analytics?appId=&range=24h\|7d\|30d` | 总览统计、时间序列与排行 |
| `GET /api/events?appId=&range=&scene=&level=&status=&q=&profileId=&offset=&limit=` | 事件分页，附带处置状态 |
| `GET /api/events/{id}` | 单个事件及反馈、处置、执行、支付结果 |
| `GET /api/devices?...&level=&sort=risk\|lastSeen\|accounts\|events` | 设备列表新增等级筛选与排序 |

原有 `/api/overview` 保留兼容。

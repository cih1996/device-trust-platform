# 知衡后台 0.6.1

后台登录改为账号密码。线上首次登录账号为 `admin`，初始密码沿用原管理口令；登录后从左下角“账号设置”修改密码。服务端只保存带随机盐的迭代摘要，页面和 API 使用短期管理会话，应用密钥仍与后台账号分开。

风险概览增加：

- 过去 24 小时业务访问、活跃设备、待关注事件和有效页面停留样本；
- 风险综合评分、低/中/高风险分布、小时活跃趋势和 IP 访问分布；
- 访问明细中的设备 ID、访问 IP、风险评分能量条、风险级别提示和页面停留时长。

页面停留统计依赖业务服务在事件 `context` 中上报 `pageName` 与 `pageDurationMs`，单位为毫秒。没有上报时后台显示“未提供”，不会把缺失数据当成零值。

应用管理入口先展示应用卡片，再进入单个应用的策略、接入保护和密钥管理。设备档案和风险事件使用当前应用上下文；选择“全部应用”可回到汇总视图。
